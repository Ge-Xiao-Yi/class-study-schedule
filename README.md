# 拾光课表

GitHub Pages 发布目标：`https://ge-xiao-yi.github.io/class-study-schedule/`。部署成功后可访问；配置和本地静态预览步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。推送 `main` 自动运行检查、静态构建与浏览器测试，再发布。

Next.js App Router、React、TypeScript、Tailwind CSS 构建的课表与学习计划网页。已实现自然周、课程、任务、本地多档案与 JSON 备份恢复。数据通过仓库接口自动保存到 IndexedDB（Dexie），成功保存后刷新或关闭浏览器重开仍保留。首次使用只初始化一次演示档案；之后新建档案使用空课表。

## 运行与检查

推荐 Node.js 24 LTS；单元测试依赖要求 Node.js 22.12+（22.x）、24.x 或 26+，具体以 package.json 的 engines 为准。依赖版本以 package-lock.json 为准。

```sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run format:check
npm run build
npm start
```

默认地址为 http://localhost:3000。现有开发预览也可使用 `npm run dev -- --hostname 127.0.0.1 --port 3001`。

浏览器测试针对生产版本，先构建，再执行：

```sh
npx playwright install chromium
npm run test:e2e
```

本机已有 Microsoft Edge 时，可在 PowerShell 设置 `$env:PLAYWRIGHT_CHANNEL='msedge'` 后执行 `npm run test:e2e`，无需额外下载。设置 `$env:CI='1'` 时 Playwright 会自动启动独立生产服务器，禁止复用旧服务；请保证 3000 端口空闲。截图和 JSON 报告在被 Git 忽略的 test-results/ 中。

## 生产交付与环境变量

当前不需要 `.env`、API 密钥、数据库连接字符串或账号服务。不要把密码放入 `NEXT_PUBLIC_*`，这些值会被打包到浏览器。`PLAYWRIGHT_CHANNEL` 和 `CI` 只用于测试；`PORT` 可配置生产监听端口，也可使用命令行参数。

安装必须使用包含开发依赖的 `npm ci`，因为构建需要 TypeScript、Tailwind 和 OCR 语言包。`prebuild` 自动生成 `public/ocr/v7`；不要跳过该步骤或遗漏该目录。锁文件固定依赖，SheetJS 来自其官方 CDN，因此安装还需要访问 `cdn.sheetjs.com`。构建本身不需要业务密钥。

部署步骤、HTTPS、资源路径和回滚说明见 [DEPLOYMENT.md](DEPLOYMENT.md)。`npm run build` 加 `npm start` 用于 Node.js 托管；GitHub Pages 使用 `npm run build:pages` 生成 `out/`，本地通过 `npm run preview:pages` 预览。

## JSON 备份与跨设备迁移

1. 开启编辑模式，进入档案区域的备份入口，导出完整 JSON；它包含全部本地档案、课程例外、任务状态、目标和关联数据，不只是当前档案。
2. 保存到自己控制的位置。JSON 是明文，包含个人课表和学习信息，分享前应确认接收人。
3. 将 JSON 文件手动传到目标设备，在目标设备打开课表网站；先导出目标设备自己的备份。
4. 选择恢复文件，核对格式版本、数据摘要，并完成二次覆盖确认。恢复会替换目标浏览器中该网站的全部本地档案，不做合并。
5. 恢复后切换档案，核对学期、课程单周例外、任务完成状态和目标。后续两台设备独立保存，不会自动同步；再次迁移时重新导出并明确哪份数据作为主版本。

同一电脑更换浏览器，或从 `localhost` 换为 `127.0.0.1`、更换端口、域名、HTTP/HTTPS，都应视为迁移。服务器重启不删除浏览器数据库，但浏览器清理站点数据、隐私模式、存储配额或回收策略可能导致数据丢失。自动保存成功不是异地备份；请定期导出。网页未提供完整离线缓存，断网时不保证能够重新打开页面。

## 使用方式

- 顶部显示本地当前日期、星期、正在进行的全部课程，以及距当天最后一门课程结束的倒计时。每秒按系统时间重算；无课、尚未上课、课间、上课中及结束分别显示，浏览其他周不影响今日状态。
- “复制上一周”以正在浏览的自然周为目标，可选择课程、任务或全部，并预览新增/跳过数量。固定课程沿用原模板和教学范围，不复制单周例外；未取消的单次课程后移七天，相同目标安排跳过。任务复用定义，只新增目标周未开始的实例，已有状态、调整和删除记录不被覆盖。
- “时间段设置”独立调整上午、下午、晚上的开始与结束时间，允许留空隙且无需覆盖全天，并按当前档案自动保存。跨段课程在相关时段显示，有开始时间的任务只在开始所属时段显示；无时间或开始时间在空隙内的任务保留手选时段；完全位于时段外的课程单独列出。
- 关闭编辑模式后只可浏览、切换周次/视图和勾选任务；课程任务管理、设置、复制以及档案修改/备份恢复入口均禁用。桌面可选择七天或单日视图，手机和平板使用单日视图，方向键/Home/End 可切换日期。
- 上一周、下一周始终移动七个自然日；日期跳转定位到对应自然周和移动端单日；返回本周定位到本地今天。
- “学期设置”维护开始日期、结束日期和教学周数。
- “新增课程”或时间格中的添加按钮打开表单，默认每周重复，可选“仅本周（一次）”。
- 点击课程卡片，默认仅修改当前自然周；选择“修改整个课程”可修改模板、重复规则与范围。
- “取消本周课程”保留恢复入口，位于课表下方；已调整的课程也可在弹窗内“恢复原安排”。
- “删除整个课程”通过确认弹窗删除模板及所有相关例外。
- “课程管理”可访问当前自然周未显示的课程，避免缩短学期或重复范围后无法管理。
- “编辑模式”默认开启；空白格和已有内容的格子均提供独立的“添加课程”和“添加任务”。关闭后进入浏览模式，仍可勾选任务打卡。
- 任务支持名称、日期、所属时间段、可选起止时间、预计耗时、截止日期、不重复/每天/每周重复和重复截止日期。
- 勾选任务即完成，取消勾选回到未开始；进行中通过任务编辑弹窗设置，状态始终只作用于当前实例。
- 编辑、删除和复制会显示范围确认，支持“仅这一次”与“整个重复任务”；复制生成独立任务且状态重置为未开始。
- “任务管理”可访问当前周以外的任务模板。改变重复规则时，已有状态和单次调整保留。

## 日期与课程规则

1. 日期使用本地 YYYY-MM-DD，时间为 HH:mm，星期为 1–7。解析使用本地正午，跨日用日历运算，避免 UTC 日期偏移和夏令时影响。
2. 自然周始终周一至周日。学期开始日所在自然周为教学第 1 周，但开始日之前不显示重复课程；结束日包含在有效范围内。教学周数不得超出学期覆盖的自然周数。
3. 每周课程只保存一个模板，读取当前周时计算发生实例。有效范围是学期日期、教学周总数与课程起止教学周的交集；不会预生成或写入每周副本。
4. “仅本周”保存具体发生日期，不受学期或教学周范围限制，下一周不会重复。编辑单次课程保留原自然周。
5. CourseException 以 courseId + originalDate 唯一关联一次发生，独立保存 modify/cancel 和覆盖字段；移动到本周另一日仍保持原始发生身份。恢复删除对应例外。
6. 修改整个模板的星期时，例外重新锚定到原自然周的新模板日期，单周覆盖值保留。缩短学期/课程范围不会删除模板或例外；重新扩大范围可恢复显示。
7. 默认上午 00:00–12:00、下午 12:00–18:00、晚上 18:00–24:00，可按档案独立自定义六个时间边界；允许空隙，无需覆盖全天，各段结束须晚于开始且三个时段按先后排列、不重叠。新课程默认录入时间会适应当前时段。课程按半开区间相交显示，跨段不生成新记录，结束恰在分界点时不显示到下一段。
8. 同格多门课程按开始时间排序。同一课程的跨段卡片共享 courseId 和 occurrenceId，今日课程按实例去重计数。第一版不支持跨午夜，结束时间必须晚于开始时间。
9. 初始样例学期从打开页面所在自然周前三周的周一开始，共 20 周。任务样例初始化为不重复的 Task 和 TaskOccurrence，可编辑、复制、删除和打卡。

## 任务模型与作用范围

- Task 保存定义和重复规则，不含状态。TaskOccurrence 保存某一次的 todo / in_progress / done、completedAt 与 overrides；不重复任务也采用相同状态模型。
- 日期和星期沿用本地自然日计算。每天按自然日重复，每周按开始日期的星期重复，repeatUntil 包含当天；dueDate 只用于截止提醒，不截断重复。
- 创建时仅保存一个起始实例；后续读取周视图只计算虚拟实例，发生修改或打卡时才写入 UUID 记录，不预生成大量数据。
- 仓库中同一 taskId + occurrenceDate 唯一。单次修改保留原 occurrenceDate，用 overrides.startDate 表示实际显示日期；跨周移入、移出均不会重复生成源实例。
- 单次删除用 overrides.deleted=true 保存墓碑，避免按重复规则重新出现；不增加数据模型之外的状态枚举。整个任务删除同时清理模板及其所有实例。
- 整组编辑仅改变模板；已记录的单次状态和覆盖保留。状态字段只更新当前选中实例，不批量覆盖其他日期。改变重复日期或规则后，已记录实例仍保留在原记录日期；不重复任务改变日期时移动同一个实例，避免出现副本。
- 单次复制取当前有效字段，副本不重复；整组复制取模板的重复规则。两者均使用新 UUID、未开始状态，不复制原实例记录；截止日期及重复截止日期按目标日期平移。
- 有开始时间时，任务归属其开始时间段；跨时段只显示一次。无开始时间时使用手选时段。起止时间均可选，只有同时填写时要求结束晚于开始，不支持跨午夜。
- 混合排序键为开始时间，若仅有结束时间则用结束时间；没有具体时间的任务排在后面，预计耗时不参与时间排序。同一时间下先课程后任务，再按稳定身份排序。
- 已完成任务显示删除线；过去未完成或超过截止日期只显示提示，不自动移动或删除。

## 当前范围与限制

已完成自然周导航、学期设置、课程新增/编辑/删除、每周和单次规则、单周修改/取消/恢复，以及任务重复、独立打卡、编辑/删除/复制范围确认和混合排序。电脑七日视图、手机和平板单日视图继续复用。

已实现持久化、多档案创建/切换/重命名/删除，以及全部档案 JSON 导出与覆盖恢复。备份格式和数据库结构版本均为 1。导入最大 20 MB，先验证字段、版本、日期、唯一性及同档案关联，再显示摘要与二次确认；请先备份。恢复在一个事务内替换全部数据，失败回滚，不合并文件。

本地档案不是安全账号：没有密码、加密或访问控制，使用同一浏览器的人可以访问全部档案，JSON 也是明文。不同协议、主机名或端口使用不同数据库；清除站点数据、隐私模式结束、浏览器空间回收可能造成丢失，应定期导出备份。存储失败不会偷偷退回临时内存。

普通跨标签页编辑不实时推送，可点击“重新加载数据”；另一标签页恢复后，旧会话写入会被拒绝并提示重新加载。长期目标支持手动与关联任务自动进度，任务编辑可选择目标；Excel/CSV 模板、字段映射、可编辑预览和本地截图 OCR 已实现。账号和云端同步未开发。后台标签页可能被浏览器降低定时器频率，返回页面时会根据当前系统时间立即校正倒计时。
