11. 推荐技术方案

根据你的需求，采用 Next.js 开发，但第一版不需要搭建完整的云端后端。

技术选型

Next.js + React + TypeScript

负责页面渲染、交互逻辑、组件组织及后续云端功能扩展。

Tailwind CSS

负责浅蓝色主题、响应式网格、卡片布局和编辑弹窗样式。

IndexedDB + Dexie

保存课程、任务、目标、用户档案及导入数据，支持结构化查询。

SheetJS / XLSX + CSV 解析

实现Excel及CSV课表文件读取、字段映射和导入预览。

OCR 识别模块

用于课表截图文字提取。第一版采用浏览器本地识别与人工确认相结合的方式。

建议使用 Zod 验证导入数据和表单数据，使用 Vitest 与 React Testing Library 编写单元及组件测试，使用 Playwright 完成主要交互流程测试。

11.1 为什么使用 IndexedDB？

你的网页需要存储重复课程、单周例外、重复任务实例、目标关联关系和多个本地用户档案。

相比直接将所有内容存入一个 localStorage 字符串，IndexedDB 更适合管理这些结构化数据。

第一版使用 Dexie 封装 IndexedDB，后续增加云端数据库时，可以保留现有数据模型和页面组件，替换或扩展数据访问层。

IndexedDB 本地数据库

各用户档案独立存储｜JSON备份与恢复

12.1 Next.js 的运行边界

第一版的课程和任务数据保存在浏览器中。

Next.js 负责提供网页应用，课程和任务的增删改查在浏览器客户端完成。

浏览器存储不能在服务器端直接访问，因此所有依赖 IndexedDB 的组件都必须在客户端初始化，并处理首次加载时的数据读取状态。

第一版不需要为了本地数据管理而额外搭建数据库服务器。
